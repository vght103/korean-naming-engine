# 인명용 한자 조합 전수 탐색 (오은상·오윤하)

이 폴더는 성 吳(원획 7)에 이름 발음 '은상'과 '윤하'를 붙일 때 쓸 수 있는 **인명용 한자 조합을 빠짐없이** 나열하고, 조합마다 사격(원·형·이·정)의 81수리 길흉을 계산한 결과다. 모든 표는 `skills/korean-naming/scripts/name_search.py`가 만든 생성물이므로 손으로 고치지 말고 다시 실행한다.

| 파일 | 내용 |
|---|---|
| `오은상_조합표.md` | 은(34자) × 상(43자) = 1,462개 조합. 글자 목록, 획수 쌍별 전수표, 네 격 모두 吉인 조합, 실무 참고표, 전체 조합표 |
| `오윤하_조합표.md` | 윤(19자) × 하(32자) = 608개 조합. 구성은 위와 같음 |
| `획수쌍_A7.md` | 성 원획 7일 때 이름 획수 B·C(각 1~30) 900쌍 가운데 네 격이 모두 吉인 70쌍 |

## 1. 핵심 수치

| 항목 | 은상 | 윤하 |
|---|---|---|
| 전체 조합 | 1,462개 (34자 × 43자) | 608개 (19자 × 32자) |
| 네 격 모두 吉 | **182개** (획수 쌍 19쌍) | **65개** (획수 쌍 10쌍) |
| 실무 참고 조합 | 40개 | 12개 |
| 정격 24이면서 네 격 모두 吉 | 획수 쌍 9·8뿐 → 吳垠尙·吳垠牀·吳垠狀 3개 | 획수 쌍 8·9뿐 → 昀·沇 × 河·昰·㰤·抲 8개 |

- **사격 공식**: 원격 = B+C, 형격 = A+B, 이격 = A+C, 정격 = A+B+C (A = 성, B = 이름 첫 자, C = 이름 끝 자의 원획).
- **네 격 모두 吉**: 네 수가 모두 수리표의 `吉`이다. 반길반흉(51·71·77)은 길로 세지 않는다.
- **실무 참고 조합**: 네 격 모두 吉이고, 두 글자 모두 KS X 1001 수록 또는 교육용 기초한자이며, 원획 확인 권장 플래그(`wonhoek_check` = Y)가 없는 조합. 日부수·순양·KS음외 같은 플래그는 걸러 내지 않고 표에 보인다.
- 최종 수치와 문장은 이 표들과 같은 값을 쓴다.

## 2. 다시 만드는 방법

저장소 루트에서 실행한다. python3(3.8 이상) 표준 라이브러리만 쓴다. 이번 생성은 Python 3.11.15로 했다.

```bash
python3 skills/korean-naming/scripts/name_search.py --surname '吳' --first '은' --second '상' --report --title '오은상(吳 + 은 + 상) 인명용 한자 조합 전수표' --out 'docs/전수탐색/오은상_조합표.md'
python3 skills/korean-naming/scripts/name_search.py --surname '吳' --first '윤' --second '하' --report --title '오윤하(吳 + 윤 + 하) 인명용 한자 조합 전수표' --out 'docs/전수탐색/오윤하_조합표.md'
python3 skills/korean-naming/scripts/name_search.py --surname '吳' --stroke-pairs --title 'A=7(吳) — 네 격이 모두 吉인 이름 획수 쌍 (B, C = 1~30)' --out 'docs/전수탐색/획수쌍_A7.md'
```

각 생성 파일 맨 위에도 같은 명령이 적혀 있다. 같은 입력이면 바이트 단위까지 같은 파일이 나온다. 이번 생성물의 sha256은 다음과 같다.

| 파일 | sha256 |
|---|---|
| `오은상_조합표.md` | `78e3cb3681b0624ab27f92c038e672592c9b195ac3574c25a5d4699b10f666f2` |
| `오윤하_조합표.md` | `eec5190025e3f0f5e6c10a52c371e0008a3e0e9886432f4ac000357c9f0b7b59` |
| `획수쌍_A7.md` | `2b69bd0583bc86e6f808f1ce5447655cfd52486c3dc69ce1928f4e2a39cdb82a` |

자주 쓰는 변형:

```bash
# 수리표가 1~81을 빠짐없이 읽히는지 점검
python3 skills/korean-naming/scripts/name_search.py --check-suri
# 두음법칙 변형 발음(倫 륜→윤 등)까지 넣어 보기
python3 skills/korean-naming/scripts/name_search.py --surname 吳 --first 윤 --second 하 --dueum --all-gil
# 반길반흉을 길로 세면 어떻게 달라지는지(민감도)
python3 skills/korean-naming/scripts/name_search.py --surname 吳 --stroke-pairs --half-as-gil
# 특정 수의 판정을 바꿔 보기(예: 51을 길로)
python3 skills/korean-naming/scripts/name_search.py --surname 吳 --stroke-pairs --suri-override '51=길'
```

## 4. 이전 임시 실행과 비교

수리표를 정리하기 전에 한 번 임시로 돌린 적이 있다. 그때는 구판 수리표에 38·51이 빠져 있어 `--suri-override '38=길,51=반길반흉'`로 채웠고, 58·71·77은 구판대로 凶이었다. 지금 수리표에서는 58이 吉, 71·77이 반길반흉이다.

| 항목 | 임시 실행 | 지금 | 이유 |
|---|---|---|---|
| 은상 네 격 모두 吉 | 182개 / 19쌍 | 182개 / 19쌍 (같음) | 은상 조합의 네 수는 최대 55라 58이 나오지 않는다. 71·77은 凶→반길반흉으로 바뀌었지만 둘 다 길로 세지 않으므로 결과가 같다 |
| 윤하 네 격 모두 吉 | 65개 / 10쌍 | 65개 / 10쌍 (같음) | 윤하 조합의 네 수는 최대 46이다. 나머지 이유는 위와 같다 |
| A=7 획수 쌍 | 68쌍 | **70쌍** | 58이 吉이 되어 28·30, 30·28(원격 58)이 새로 들어왔다 |
| 실무 참고 조합 | (기준이 달랐음) | 은상 40개, 윤하 12개 | 원획표에서 胤에 육달월 위치 확인 플래그가 새로 붙어 吳胤瑕가 실무 참고표에서 빠졌다 |

원획표 개정(강희자전·대자원 배열 위치로 25자의 원획을 1 낮춤, 육달월 위치 플래그 27자 추가)은 '은·상·윤·하' 글자의 원획을 바꾸지 않았다. 바뀐 것은 胤의 확인 권장 플래그뿐이다.

## 5. 한계

1. **인명용 한자 범위의 시차.** 이 표의 대상 한자는 Unihan의 인명용(N)·교육용(E) 표지, 곧 **2018년 대법원 목록**까지다. 대법원 인명용 한자는 2024-06-11 시행 개정으로 9,389자가 되었고, 그 추가분은 여기에 없다. 반대로 여기 있는 글자도 출생신고 직전에 [대법원 인명용 한자 조회](https://efamily.scourt.go.kr/cs/CsBltnWrtList.do?bltnbordId=0000010)로 자형과 지정 발음을 다시 확인해야 한다.
2. **반길반흉은 길로 세지 않았다.** 51·71·77이 사격에 들어가면 네 격 모두 吉에서 빠진다. 81수리 길흉표 자체가 정본이 없는 전통 체계이고, 자료마다 판정이 갈리는 수가 있다(`suri_table.md` '이설' 칸).
3. **뜻과 불용문자는 판단하지 않는다.** 표는 수리·음양·오행 분류값만 나열한다. 예를 들어 실무 참고표에도 瑕(티·흠), 殷(은나라·많을), 峠(일본 국자로 알려진 글자, '고개') 같은 글자가 그대로 들어 있다. 이름으로 쓸지는 사람이 뜻을 보고 정한다. 불용문자는 공인된 목록이 없어 걸러 내지 않았다.
4. **훈음**은 libhangul 사전의 첫 뜻이라 대법원 지정 훈과 다를 수 있다(예: 垠 '언덕 은' — 대법원 조회 '땅가장자리 은', 潤 '불을' — 통용 '윤택할 윤', 昀은 훈 없음).
5. **원획**은 강희자전 기준 규칙으로 계산했다. 자료마다 갈리는 글자는 '획확인' 플래그로 표시했으니 옥편으로 다시 확인한다.
6. **자원오행**은 부수만 보고 정한 휴리스틱이다(빈칸 = 부수 관행 없음). 획수오행·발음오행·자원오행은 서로 다른 분류법이며 사주 오행 개수에 더하지 않는다.
7. **KS X 1001**은 글꼴·입력 편의의 기준일 뿐 출생신고 가능 여부와는 별개다. 예컨대 昀은 KS X 1002에만 있고, 沇은 KS X 1001에 '연'으로만 실려 있어 한글 '윤'으로 한자 변환하면 나오지 않을 수 있다.
8. **두음법칙 경로**(예: 侖·倫 '륜'→'윤')는 기본 표에 넣지 않았다. `--dueum`으로 따로 볼 수 있고, 실제 허용 여부는 대법원 조회로 확인한다.
