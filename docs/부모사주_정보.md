### 월령 기준 분석 (핵심)

- **일간**: 癸水 (음수, 작은 물)

- 午가 2개(연지·월지)이고 午月 당령이라 火 기운이 강하다.
- 일지 亥는 癸의 12운성 **제왕**(壬 기준으로는 건록)으로 일간을 돕는 뿌리다. 다만 午午의 火를 감당하기에는 부족하다고 보는 해석이다.
- 庚金이 金生水로 돕지만 1개뿐이다.

**해석 — 실질 부족: 水(午月 囚)·木(겉글자 없음)**
**해석 — 실질 과다: 火 (午月 당령)**
**용신(해석, 시주 제외 삼주 기준, 유파·판단 방식에 따라 다를 수 있음): 金·水**

### 지금 말할 수 있는 것과 없는 것

- **丙은 연간(年干)이지 일간(日干)이 아니다.** 아이의 일간·일간 강약·용신은 일주가 정해져야 판단할 수 있다. 따라서 초판의 "아이 丙火 건록", "火 과다 확정", "용신 金·水 확정", "木·金 부재 확정"은 모두 오류다.
  - 참고로 丙의 12운성은 巳 = 건록, 午 = 제왕(양인), 亥 = 절이다.
- 위 개수는 **연·월 겉글자 4자만** 센 값이다. 일주·시주 4자와 지장간이 빠져 있으므로 "木 0·金 0"을 전체 사주의 결핍으로 확대하지 않는다(己亥月이면 亥 속에 甲木, 戊戌月이면 戌 속에 辛金이 있다).
- 이름의 획수오행·자원오행·발음오행은 사주 오행과 **서로 다른 분류법**이다. 겉글자 개수에 더해 "보완 후 金 2"처럼 합산하지 않는다.
- **작명 방향(가설)**: 연·월 겉글자 4자에서 비는 오행은 시나리오마다 다르다 — 戊戌月 木·金·水, 己亥月 木·金, 庚子月 木·土. 초판의 "金·水 보완" 방향은 己亥月·火 과다를 전제한 가설이다. 이름의 사주 보완 가치는 시나리오에 따라 달라진다.
  - **戌月**(가을·건조, 午戌 火 반합)이면 水(河) 보완의 조후 의미가 커진다.
  - **亥月**(겨울; 왕상휴수사로 水旺 木相 金休 土囚 火死)이면 水 추가 필요성이 줄고, 오히려 火·木을 보는 해석도 가능하다.
  - **庚子月**도 겨울 水旺 구간이라 亥月과 같은 방향으로 재평가가 필요하다.
  - → **출생 후 일주·시주를 계산해 재평가한다.**

## 부모-자녀 관계 (겉글자 비교, 상징적 참고)

> 아래는 부모 **일간**과 아이 **연간** 丙 한 쌍을 비교한 상징적 관계다. 서로 다른 사람의 명식 글자끼리 대조하는 것 자체가 해석 영역이며, 부모·자녀의 실제 관계나 아이의 성격을 정하지 않는다. 실제 비교는 아이 일간이 확정된 뒤 다시 한다.

### 아버지(일간 癸水) ↔ 아이(연간 丙火)
- 오행: **水克火** — 癸가 丙을 극한다.
- 십신: 癸 기준 丙 = **정재**, 丙 기준 癸 = **정관**.
- **癸丙은 천간합이 아니다.** 천간합은 甲己·乙庚·丙辛·丁壬·戊癸 다섯 쌍뿐이며, 癸의 합 짝은 戊, 丙의 합 짝은 辛이다. 초판의 "癸丙 합화"는 삭제했다. 천간충(甲庚·乙辛·丙壬·丁癸)에도 癸丙은 없다.

### 어머니(일간 甲木) ↔ 아이(연간 丙火)
- 오행: **木生火** — 甲이 丙을 생한다.
- 십신: 甲 기준 丙 = **식신**, 丙 기준 甲 = **편인**.

### (참고) 다른 겉글자 비교
- 아버지 월간 壬 ↔ 아이 연간 丙: **丙壬 충**.
- 어머니 월간 庚 ↔ 아이 연간 丙: **丙克庚**(火克金).
- 부모 시주는 출생 시각 미상으로 분석에서 제외했으므로 시간(時干)과의 비교는 하지 않는다. "겉글자 비교 참고"로만 쓴다.

## 출생 시각 안내

- 초판에 있던 **출생 시간대별 유불리 표는 삭제했다.** 아이 일간이 미정이라 시간대 유불리를 판단할 근거가 없고, 문서마다 추천 시간대가 서로 달랐다.
- 출생 시각은 **분 단위**로 기록한다(절입 전후라면 초까지). 출생지(병원 소재지)도 함께 기록한다.
- 시주·일주는 출생 후 `saju_calc.py`로 계산한다. 시지 경계(30분 보정 기준) 근처 출생이면 계산기가 보여 주는 대안 간지도 함께 적는다.
- 23:30 이후 출생은 정자시법으로 **다음 날 일주**를 쓴다. 당일 일주를 유지하는 야자시 유파도 있어 계산기가 대안을 함께 보여 준다.
- 균시차(진태양시)는 적용하지 않는다. 동경 127.5° 기준 11월 진태양시는 상·중순 KST −14~16분, 하순 −16~−19분 정도로, 일괄 30분 보정과 차이가 난다.
- **분만 시기·방식은 의료진의 임상 판단에 따른다.** 사주를 이유로 출생 시각을 고르지 않는다.

## 작명 후보 이름 (출생 전 조건부 비교)

- **사격(원형이정) 공식, 원획 기준** — 성 A, 이름 첫 자 B, 이름 끝 자 C:
  - 원격(초년운) = B + C
  - 형격(청장년운) = A + B ← "성명의 중심(심장)"
  - 이격(중년운) = A + C
  - 정격(총운, 말년 포함) = A + B + C
  - 연령 배당은 자료마다 다르다. 초판의 공식(원 = A+B, 형 = B+C)은 폐기했다. 네 수의 집합은 같고 격 이름표만 바뀐다.
- 길흉은 `skills/korean-naming/references/suri_table.md` 정본(吉 39 · 반길반흉 3(51·71·77) · 凶 39, 3단계)을 따른다. 반길반흉은 길로 세지 않는다. 大吉 등급은 자료마다 달라 재현할 수 없으므로 쓰지 않는다(초판의 "大吉 3 + 吉 1" 표현 폐기).
- 후보 번호는 초판의 순서이며 우열 판정이 아니다. 두 후보의 사주 보완 가치는 아이 월주·일주 확정 후 재평가한다.
- 획수오행·발음오행·자원오행은 서로 다른 분류법이다. 아이 사주 오행 개수에 더하지 않는다. 발음오행은 운해본(현행 작명계 다수, ㅇㅎ = 土) 기준이며, 훈민정음 해례본 기준(ㅇㅎ = 水)이면 결과가 달라진다.
