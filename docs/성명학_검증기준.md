## 1. 사격(四格) 공식 — 고정

성 = A, 이름 첫자 = B, 이름 끝자 = C

```
원격 = B + C     초년 (1~25세)
형격 = A + B     중년 (25~45세)  ← 성명의 심장
이격 = A + C     말년 (45~65세)
정격 = A + B + C 총운 (일생)
```

`name_suri.py` 와 irum.com 이 동일 공식임을 교차검증 완료.

> **[현행]** 같은 공식이 현행 `skills/korean-naming/SKILL.md` · `scripts/name_search.py`(`"원": b + c, "형": a + b, "이": a + c, "정": a + b + c`)에 들어 있다.
> `name_suri.py` 는 현재 교차검증용이다. 연령 배당(초년·중년·말년 구간)은 자료마다 달라 현행 `CLAUDE.md` 는 원격 = 초년운, 형격 = 청장년운, 이격 = 중년운, 정격 = 총운(말년 포함)으로 적는다.

> **폐기**: 2026-03 문서의 「원격=A+B, 형격=B+C」는 다른 유파 공식. 사용 금지.
> 숫자 집합은 같으나 라벨이 뒤바뀌어 형격(심장) 판정이 달라진다.

### 절차 (새 한자를 후보에 올릴 때마다)

1. 조회 화면에 **쓰려는 한글음**을 입력한다 (한자가 아니라 음이다)
2. 결과 목록에 그 한자가 있는지 확인한다
3. 있으면 `교육용` / `별표1` 중 어느 쪽인지 기록한다
4. 없으면 **그 음으로는 쓸 수 없다** — 후보에서 제외한다
5. 아래 §3 검증 완료 한자표의 `인명용` 열에 결과를 추가한다

**조회 방법 (재현용).** 결과 한자는 페이지 텍스트에 없고 CSS 클래스에 유니코드로 인코딩되어 있다
(`whj_000091c7` → `0x91C7` → 采). 브라우저 콘솔에서 아래로 추출한다:

```js
fnLoadKsndSearch('채');                       // 한글음으로 조회
[...document.querySelectorAll('#listUnicodeByKsnd .charinfo')].map(b => {
  const cls = [...b.querySelector('div').classList].find(c => /^whj_[0-9a-f]+$/i.test(c));
  return { ch: String.fromCodePoint(parseInt(cls.replace('whj_',''),16)),
           인명용: b.dataset.isinmyung, 훈음: b.dataset.inhun };
});
```

> **주의**: 이 조회는 `인명용 여부(isinmyung)`만 알려주고 **`교육용` / `별표1` 구분은 제공하지 않는다.**
> 아래 §3 표의 해당 열은 별도 분류이며 이 조회로는 검증되지 않는다.

### 이 프로젝트의 한계 (반드시 고지)

인명용 한자 여부는 **네트워크 조회가 필요하므로 `verify.py` 가 자동 검증하지 못한다.**
`verify.py` [10]단계는 "표의 모든 한자에 `인명용` 값이 비어 있지 않은가"라는 **누락 검사만** 한다.
값 자체가 맞는지는 위 절차로 사람이 확인해야 하며, 최종 후보는 **출생신고 전 재조회**를 권장한다.

> **[현행]** `verify.py` 는 구 로컬 계보의 `scripts/verify.py` 다(원문의 [10]단계는 그 스크립트에서 [11]단계로 번호가 붙어 있다).
> 현행 `skills/korean-naming/data/inmyeong_hanja.tsv` 의 인명용 표지는 Unihan 기준 대법원 2018 목록까지라

- **A → 오윤채 승** (유일하게 완전 순행)
- **B → 동률이나 오채윤 우위.** 오윤채의 상극이 하필 성씨가 **조후 1순위 水를 담당하는 유일 글자(潤)를 직격**하는 형태다.
  오채윤의 상극은 이름→성씨 방향이라 보완 글자 둘 다 무사하다.
- **C → 둘 다 상극 0 동률.** 승부가 음령·23수 배치로 넘어가며 오채윤이 근소 우위.

→ (당시 판단) **오채윤은 세 시나리오 어디서도 2위 밑으로 떨어지지 않는 유일한 후보다.**

### 이것은 이 프로젝트만의 허점이 아니다

학술 논문 [「한국 성씨한자(姓氏漢字)의 자원오행(字源五行)에 대한 고찰」](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART002360488)
은 **"현행 작명 현장에서 성씨 한자의 자원오행 배속에 오류가 심각"** 하다고 지적하며,
100대 성씨한자를 오행성의 명료도에 따라 **강·중·약·무의미·불명**으로 분류하고
"오행성이 분명한 성씨한자와 모호한 성씨한자를 구분해 작명하는 이론 체계"를 제안한다.

즉 **성씨 자원오행이 갈리는 것은 학계가 인정한 미해결 문제**이며, 吳(부수 口)가
「무의미/불명」군에 속할 가능성이 있다. 이 경우 아래 3안(성씨 제외)이 학술적으로도 정합적이다.

1. irum.com·miso.co.kr 등 채택 출처에서 **성씨 吳의 자원오행** 표기를 직접 확인
2. 또는 "성씨는 자원오행 판정에서 제외하고 이름 두 글자만 본다"는 규칙을 명시적으로 채택
   (이 경우 采-潤 / 潤-采 둘 다 水生木 상생으로 **동률**이 되어 자원오행은 변별력을 잃는다)
3. 어느 쪽을 택하든 **본 문서 §3 검증표의 `(성씨)` 칸을 채우고**, 그 근거를 여기에 적을 것
