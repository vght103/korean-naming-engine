# 우리 아기 이름 후보 — 한눈에 정리 (2026-10)

> 성은 **오(吳)**, 아기는 **여자아이**, 2026년 11월에 태어날 예정입니다.
> 이 문서는 지금까지 본 이름 후보를 모두 모아 **쉽게** 정리한 것입니다. 숫자는 프로젝트 도구로 계산한 값입니다.
> 이름 숫자 풀이는 옛날부터 내려오는 **전통 풀이**이고, 이름이 미래를 정하지는 않습니다.

---

## 0. 이름 숫자 보는 법 (1분 설명)

1. **획수**: 한자마다 긋는 횟수가 있어요. 吳(오)는 7획입니다.
2. **숫자 4개(사격)**: 획수를 이렇게 더합니다.
   - 원격 = 이름 두 글자 → **어린 시절**
   - 형격 = 성 + 이름 첫 글자 → **청년 시절** (가장 중요하게 봄)
   - 이격 = 성 + 이름 끝 글자 → **중년**
   - 정격 = 세 글자 전부 → **인생 전체**
3. **좋은 수(吉) / 안 좋은 수(凶)**: 4개가 모두 좋은 수면 합격. 아래 후보는 **전부 4개 모두 좋은 수**입니다 (오여울은 한글 이름이라 계산하지 않음).
4. **추가로 본 조건**: 한자끼리 서로 부딪히는 오행이 없는지, 발음이 자연스러운지, 컴퓨터로 입력되는 글자인지, 여자아이 이름으로 실제 쓰이는지.

## 5. 꼭 기억할 것

1. **숫자로는 위 후보들 사이에 우열이 없습니다.** 다 합격이에요. 고르는 기준은 뜻, 부르기, 쓰기 쉬움, 그리고 마음에 드는지입니다.
2. **아기가 태어나면** 태어난 날짜·시각(분까지)으로 사주를 계산해서 이름과 잘 맞는지 한 번 더 봅니다.
3. **출생신고 직전**에는 대법원 '인명용 한자 조회'에서 한자 모양과 읽는 소리를 꼭 다시 확인합니다.
