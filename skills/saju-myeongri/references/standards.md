# 채택 기준 선언 (이 스킬의 모든 풀이가 따르는 고정 기준)

답변 일관성을 위해 아래 기준을 고정한다. 사용자가 다른 기준을 명시 요청하면 그 기준으로도 풀이하되, 기본 기준 결과를 함께 표기한다.

## 명리학

| 항목 | 채택 기준 | 비고 |
|---|---|---|
| 학파 | 자평명리(子平命理) | 연해자평·자평진전·적천수·궁통보감의 통설 |
| 년주 경계 | 입춘 절입 시각 | 음력 1월 1일 아님 |
| 월주 경계 | 12절(節) 절입 | 입춘·경칩·청명·입하·망종·소서·입추·백로·한로·입동·대설·소한 |
| 일주 경계 | 23:00 (보정 후 시각) | 정자시법. 야자시법(23~24시 당일 일주)은 비채택 |
| 시주 | 오서둔(五鼠遁) | 갑기일 갑자시 시작 |
| 서머타임 | 자동 -1시간 | 한국 1948~1951, 1955~1960, 1987~1988 (스크립트 내장 기간표) |
| 진태양시 | 기본 -30분 | 동경 135° 표준시 vs 한반도 중앙 약 127.5° (경도차 7.5° ≈ 30분) |
| 지장간 | 통용 여기·중기·정기표 | 스크립트 내장 |
| 대운 | 양남음녀 순행, 음남양녀 역행 | 대운수 = 절입까지 일수 ÷ 3, 반올림, 최소 1 |

## 성명학

| 항목 | 채택 기준 | 비고 |
|---|---|---|
| 수리 체계 | 구마사키식 사격(원형이정) + 81수리 | 기원: 채침 81수원도(송) → 구마사키 겐오 오격부상법(1929, 일본) → 일제강점기 한국 유입 |
| 한자 획수 | 원획법(강희자전) | 부수 원형 획수: 氵=4(水), 扌=4(手), 艹=6(艸), 阝좌=8(阜), 阝우=7(邑), 王=5(玉), 月(육달월)=6(肉), 辶=7(辵), 犭=4(犬), 礻=5(示), 衤=6(衣), 숫자 한자는 의미 수(四=4? → 원획법상 四=5획이나 수의성명학에서는 4) — 숫자 한자(一~十)는 획수 아닌 의미수 사용 |
| 발음오행 | 통용(운해본 계열): ㄱㅋ=목, ㄴㄷㄹㅌ=화, ㅇㅎ=토, ㅅㅈㅊ=금, ㅁㅂㅍ=수 | 훈민정음 해례본은 ㅁㅂㅍ=토, ㅇㅎ=수로 정반대. 학파 논쟁 존재 — 풀이 시 1회 고지 |
| 81 초과 수 | 81을 뺀 수로 환원 | 예: 82→1 |

## 공신력에 대한 입장 (사용자 질문 시 이렇게 답한다)

1. **계산 영역(만세력·획수·수리)은 객관적으로 검증 가능** — 천문 절기 데이터 기반이며 이 스킬은 결정론적 스크립트로 계산하므로 항상 동일하다.
2. **해석 영역은 전통 학문이지 과학이 아니다** — 통계적·과학적 근거는 입증된 바 없다. 이 스킬의 해석은 고전(자평진전 등)과 한국 통용 기준을 따르며, "전통적으로 이렇게 해석한다"의 공신력이다.
3. **학파 차이가 있는 지점은 위 표대로 고정**하고, 차이가 있다는 사실 자체를 숨기지 않는다(특히 발음오행, 야자시, 진태양시).
