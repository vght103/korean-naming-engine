## 2. 십신(십성) 의미

일간(나)을 기준으로 다른 글자와의 오행 생극 + 음양 관계로 정한다. 계산은 스크립트가 한다.

| 십신 | 관계 | 핵심 의미 | 과다 시 | 부족 시 |
|---|---|---|---|---|
| 비견 | 같은 오행, 같은 음양 | 형제, 동료, 자립심, 고집 | 독선, 재물 분산 | 협력 부족, 고립 |
| 겁재 | 같은 오행, 다른 음양 | 경쟁자, 승부욕, 추진력 | 재물 손실, 충돌 | 추진력 약함 |
| 식신 | 내가 생함, 같은 음양 | 의식주, 표현, 연구, 낙천 | 나태, 산만 | 표현력 부족 |
| 상관 | 내가 생함, 다른 음양 | 재능, 언변, 비판, 파격 | 구설, 관재 | 창의성 부족 |
| 편재 | 내가 극함, 같은 음양 | 사업 재물, 유통, 풍류 | 투기, 낭비 | 재테크 약함 |
| 정재 | 내가 극함, 다른 음양 | 고정 수입, 성실, 검소 | 인색, 소심 | 안정 수입 약함 |
| 편관(칠살) | 나를 극함, 같은 음양 | 권력, 카리스마, 무관, 시련 | 압박, 건강 부담 | 절제력 부족 |
| 정관 | 나를 극함, 다른 음양 | 명예, 직장, 원칙, 책임 | 경직, 체면 치레 | 조직 부적응 |
| 편인 | 나를 생함, 같은 음양 | 특수 학문, 직관, 의심, 재치 | 변덕, 고독 | 직관 부족 |
| 정인 | 나를 생함, 다른 음양 | 학문, 문서, 모친, 수용 | 의존, 게으름 | 학업·후원 약함 |

육친 배속(남명): 정재=처, 편재=부친, 관성=자식, 인성=모친.
육친 배속(여명): 관성=남편, 식상=자식, 인성=모친, 재성=부친.

## 3. 합·충·형·파·해

### 천간합 (합화 오행)
갑기합토, 을경합금, 병신합수, 정임합목, 무계합화

### 지지 육합
자축합토, 인해합목, 묘술합화, 진유합금, 사신합수, 오미합화(또는 불변)

### 삼합 (강력한 오행국)
인오술→화국, 사유축→금국, 신자진→수국, 해묘미→목국

### 방합 (계절 합)
인묘진→목(봄), 사오미→화(여름), 신유술→금(가을), 해자축→수(겨울)

### 충 (정면 충돌 — 변동·이동·갈등)
자오충, 축미충, 인신충, 묘유충, 진술충, 사해충

### 형 (조정·수술·관재 등 마찰)
인사신 삼형(지세지형), 축술미 삼형(무은지형), 자묘형(무례지형), 진진·오오·유유·해해 자형

### 파 / 해 (보조적 흉의)
파: 자유, 축진, 인해, 묘오, 사신, 술미
해: 자미, 축오, 인사, 묘진, 신해, 유술

해석 우선순위: 삼합·방합 > 충 > 육합 > 형 > 파·해. 합과 충이 겹치면 정황(거리, 개입 글자)을 보고 판단한다.

## 4. 신강/신약과 용신

- **신강**: 일간과 같은 오행(비겁)·생해주는 오행(인성)이 많음 → 힘을 빼는 식상·재성·관성이 용신 후보
- **신약**: 극하거나 설기하는 글자가 많음 → 인성·비겁이 용신 후보
- 판단 기준(통용 간이법): 월지가 일간을 돕는가(득령), 일지가 돕는가(득지), 천간·지지에 아군이 많은가(득세). 2개 이상이면 신강 경향.
- **조후**: 한여름(사오미월) 출생은 수, 한겨울(해자축월) 출생은 화가 시급한지 먼저 본다 (궁통보감 관점).
- 용신은 단정하지 말고 "유력한 용신 후보"로 제시하고 근거를 명시한다 — 용신 판단은 명리에서 가장 학파차가 큰 영역이다.

## 5. 십이운성 (일간 기준 지지의 에너지 단계)

장생→목욕→관대→건록→제왕→쇠→병→사→묘→절→태→양 의 12단계 순환.
양간은 순행, 음간은 역행 배치.

| 운성 | 의미 |
|---|---|
| 장생 | 탄생, 시작, 순수한 성장 |
| 목욕 | 미숙한 멋부림, 풍류, 시행착오 |
| 관대 | 사회 진출, 패기, 좌충우돌 |
| 건록 | 자립, 안정적 활동력 |
| 제왕 | 정점, 강한 주체성, 독선 위험 |
| 쇠 | 완숙 후 내리막 시작, 노련함 |
| 병 | 활동력 저하, 감성·동정심 |
| 사 | 정적, 학문·기술 몰두 |
| 묘 | 수렴, 저장, 알뜰함 |
| 절 | 단절과 전환, 변화 무쌍 |
| 태 | 잉태, 새 기획, 불안정한 희망 |
| 양 | 양육, 준비, 온건 |

## 6. 주요 신살 (통용 빈도 높은 것만)

| 신살 | 찾는 법 | 의미 |
|---|---|---|
| 천을귀인 | 일간 기준: 갑무경→축미, 을기→자신, 병정→해유, 신→인오, 임계→사묘 | 최고 길신, 위기 시 귀인 |
| 도화(연살) | 년지/일지 기준: 인오술→묘, 사유축→오, 신자진→유, 해묘미→자 | 매력, 인기, 이성사 |
| 역마 | 인오술→신, 사유축→해, 신자진→인, 해묘미→사 | 이동, 변화, 해외 |
| 화개 | 인오술→술, 사유축→축, 신자진→진, 해묘미→미 | 예술, 종교, 고독한 재능 |
| 괴강 | 일주가 경진·경술·임진·무술 | 극단적 총명/강인, 파란 |
| 백호 | 갑진·을미·병술·정축·무진·임술·계축 | 강렬한 기운, 사고 주의 전승 |
| 공망 | 일주 순(旬) 기준 빈 지지 2개 | 해당 글자 작용 약화, 정신적 지향 |

신살은 보조 참고로만 쓰고, 본 해석(오행·십신·용신)을 뒤집지 않는다.

## 7. 대운·세운 읽기

- 대운 10년: 천간 5년 + 지지 5년 가중으로 보되, 지지(환경)를 더 무겁게 본다.
- 대운·세운 글자가 원국의 용신을 도우면 길운, 기신을 도우면 어려운 시기로 본다.
- 대운/세운이 원국과 합·충하는 글자를 반드시 확인 — 충은 변동(이직·이사·관계 변화)의 신호로 해석.
- 단정 금지: "좋다/나쁘다"가 아니라 "어떤 영역(재성→재물, 관성→직장 등)에 변화 에너지가 들어온다"로 표현.
