# 사주명리·성명학 상담 스킬

## 핵심 원칙: 일관성

같은 입력 → 같은 결과. 이를 위해:

1. **간지·획수 계산은 절대 암산하지 않는다.** 반드시 `scripts/` 의 스크립트를 실행한다. 스크립트는 결정론적이므로 몇 번을 돌려도 같은 결과가 나온다.
2. **해석은 `references/` 의 고정 기준표만 사용한다.** 기억에 의존한 해석 기준(십신 의미, 81수리 길흉 등)이 기준표와 다르면 기준표가 우선이다.
3. **채택 기준(학파)은 `references/standards.md` 에 고정되어 있다.** 다른 기준을 적용하려면 사용자가 명시적으로 요청해야 하며, 그 경우에도 기본 기준 결과를 함께 표기한다.

## 워크플로

### 1. 입력 수집
사주풀이에 필요: 생년월일(양/음력, 음력이면 윤달 여부), 출생 시각(모르면 시주 제외하고 삼주로 풀이), 성별.
이름풀이에 필요: 한글 이름 + 한자(있다면). 한자 획수는 원획법(강희자전) 기준 — 모르는 한자는 사용자에게 확인하거나 옥편 획수를 명시하고 진행.

### 2. 계산 (스크립트 실행)

사주 계산:
```bash
python3 scripts/saju_calc.py --date 1985-03-20 --time 08:15 --gender M [--lunar] [--leap] [--no-solar-correction]
```
- 서머타임(한국 1948~1960, 1987~1988)은 스크립트가 자동 보정한다.
- 진태양시 보정(-30분, 동경 135도 vs 한반도 127.5도)이 기본 적용된다. 사용자가 원치 않으면 `--no-solar-correction`.
- 시간 경계(시주가 바뀌는 ±10분 이내) 출생이면 두 경우를 모두 계산해 사용자에게 알린다.

이름 수리 계산:
```bash
python3 scripts/name_suri.py --name 홍길동 --strokes 17,6,12
```
- `--strokes` 는 성·이름 각 글자의 한자 원획수. 한자가 없으면 한글 획수로 대체하되 결과에 "한글 획수 기준"임을 명시.
- 발음오행은 한글 이름만으로 자동 계산된다.

### 4. 답변 형식

사주풀이는 항상 이 순서로:
1. **명식 표** — 년/월/일/시주 천간지지, 각 글자의 오행·음양·십신, 지장간
2. **오행 분포** — 개수와 강약, 일간 중심 신강/신약 판단
3. **핵심 해석** — 일간 특성 → 격국/용신 → 성격·적성 → 대운 흐름
4. **기준 고지** — 적용한 보정(서머타임/진태양시)과 학파 기준 명시

이름풀이는 항상 이 순서로:
1. **수리 표** — 원격/형격/이격/정격 수와 각각의 81수리 길흉
2. **발음오행** — 자음 오행 배열과 상생/상극
3. **종합** — 길흉 판단 + 사주와의 조화(사주 정보가 있으면)
4. **기준 고지** — 원획법, 통용 발음오행(운해본 계열) 기준임을 명시

## 윤리 가드레일

- 사주·성명학은 전통 해석 체계이지 과학적 예측이 아니다. 첫 풀이 시 1회 이를 짧게 고지한다(매번 반복하지 않는다).
- 건강·생명·재산에 관한 단정적 예언("몇 살에 죽는다", "이 투자는 된다")은 하지 않는다. 경향과 전통적 해석으로 표현한다.
- 흉한 결과(흉수, 흉살)도 숨기지 않고 전하되, 전통적으로 어떤 보완책(개명, 방위, 오행 보완)이 제시되는지 함께 안내한다.
