# 인명용 한자 데이터 (`inmyeong_hanja.tsv`)

출생신고에 쓸 수 있는 한자 전체를 한 표로 정리한 데이터다. 글자마다 인명용 발음, 원획(原劃), 획수오행, 부수 자원오행(휴리스틱), 훈음, 원획 확인 권장 여부를 붙였다.
`scripts/build_hanja_table.py`로 언제든 같은 결과를 다시 만들 수 있다. 출력은 코드포인트 순으로 정렬되며, 입력이 같으면 바이트 단위까지 같다.

| 항목 | 값 |
|---|---|
| 행 수 | **8,094자** (머리행 제외) |
| 열 수 | 20열 (4절 끝의 `wonhoek_check` 포함) |
| 교육용 기초한자(E) | 1,800자 (이 가운데 73자는 인명용 표지 N도 함께 붙음) |
| 인명용 전용(N만) | 6,294자 |
| `kKoreanName` 연도 | 2015년 목록 6,249자, 2018년 추가 118자 |
| 훈음(`hun`) 채워진 행 | 7,189자 |
| 원획 확인 권장(`wonhoek_check` = Y) | 190자 |

## 1. 데이터 출처와 버전

| 자료 | 버전·고정값 | 라이선스 | 쓰는 곳 |
|---|---|---|---|
| Unihan (Unicode 18.0.0) | npm `@mandel59/mojidata@1.9.1`의 `dist/moji.db`. 패키지 `download.txt`에 `Unihan.zip` sha256 `4c93ea9c1f63…c63d43e`가 고정되어 있음. 이번에 쓴 `moji.db`의 sha256은 `c8cd43031d6a48bde6b131f0fd0fb778301627846c4b65ff038937884c21ea6b`. | Unicode License v3 (mojidata 패키지: MIT AND BSD-3-Clause AND CC-BY-SA-2.1-JP AND Unicode-3.0) | 인명용·교육용 표지, 읽기, 부수·획수, 영문 뜻, 강희자전·대자원 위치 |
| 같은 `moji.db`의 `ids` 표 (CHISE 계열 IDS, 출처 자형별) | 위와 같음 | 위와 같음 | 육달월(月=肉) 위치 판정(4절) |

사용한 Unihan 필드는 다음과 같다.

- `kHangul`: 읽기와 표지. `N`은 대법원 인명용 한자표, `E`는 교육용 기초한자 1,800자, `0`/`1`은 KS X 1001/1002 수록 읽기, `X`는 표준에 없는 읽기다.
- `kKoreanName`: 인명용 한자표에 실린 해(2015 또는 2018).
- `kKoreanEducationHanja`: 교육용 기초한자 지정 연도(2007).
- `kRSUnicode`: 강희 부수와 나머지 획수.
- `kTotalStrokes`: 총획.
- `kKangXi`: 『康熙字典』 쪽·자리 번호.
- `kDaeJaweon`: 『大字源』(동아출판사, 한국 자전) 쪽·자리 번호. 강희자전 위치의 교차 확인에 쓴다(4절).
- `kDefinition`: 영문 뜻.

가족관계등록규칙은 교육용 기초한자를 인명용 한자에 포함하므로, 이 표는 `N` 또는 `E` 표지가 붙은 글자를 모두 담는다.

## 2. 다시 만드는 방법

```bash
# 1) Unihan DB (npm 레지스트리에서 받음, 약 100MB)
curl -sSLO https://registry.npmjs.org/@mandel59/mojidata/-/mojidata-1.9.1.tgz
#   integrity: sha512-cqAizyE6D+ZoSLViHCulervFs0AvTyW1TazSchxWUzQdSOvZBmKv9VXH+iQclOGd7JMWLSYCQBph9rVapzIj0Q==
tar xzf mojidata-1.9.1.tgz        # → package/dist/moji.db
sha256sum package/dist/moji.db    # c8cd4303…4c21ea6b

# 2) 훈음 원본 (선택)
curl -sSLo hanja.txt https://raw.githubusercontent.com/libhangul/libhangul/main/data/hanja/hanja.txt
sha256sum hanja.txt               # b1004034…be3b 와 같아야 같은 hun 열이 나온다

# 3) 생성 (python3 표준 라이브러리만 사용)
python3 skills/korean-naming/scripts/build_hanja_table.py \
    --mojidb package/dist/moji.db \
    --out skills/korean-naming/data/inmyeong_hanja.tsv \
    --hun hanja.txt
sha256sum skills/korean-naming/data/inmyeong_hanja.tsv   # d7c82d49…b210b0f
```

실행하면 표준오류(stderr)에 다음 내용이 출력된다. 검증이 하나라도 어긋나면 종료 코드 1로 끝난다.

- 생성물 sha256, 행 수
- 규칙별·플래그별 건수, 확인 권장 건수
- 강희·대자원 위치로 T 대신 K를 쓴 글자 목록, 육달월 위치 플래그 글자 목록
- 강희 위치 보정 행의 대자원 교차 확인 통계
- 기준 원획 42자 검증, 후보 글자 플래그 검증
- `尙`/`尚` 비교

`--hun`을 빼면 `hun` 열만 빈칸이 되고, 나머지 열은 같다.

## 3. 열 설명

TSV는 UTF-8, 탭 구분, 따옴표 없음(`csv.QUOTE_NONE`)이다. 열 이름으로 읽기를 권한다. `radical_char` 이후 다섯 열은 작업 지시서에 없던 추가 열이다.

| 열 | 뜻 |
|---|---|
| `hanja` | 한자 |
| `codepoint` | `U+XXXX` |
| `inmyeong_readings` | `N` 또는 `E` 표지가 붙은 읽기만 쉼표로 나열(예: 沇 `연,윤`) |
| `all_readings` | `kHangul`의 모든 읽기(예: 李 `리,이`, 여기서 `이`는 KS 표지만 있음) |
| `education` | 교육용 기초한자(`E`)면 `Y` |
| `koreanname_year` | `kKoreanName` 연도(2015/2018). 교육용 전용 글자는 빈칸 |
| `radical_no` | 원획 계산에 **실제로 쓴** 강희 부수 번호(기본은 `kRSUnicode` 첫 값. 바뀐 경우 `wonhoek_rule` 플래그로 표시) |
| `radical_simplified` | 그 부수가 간화 자형(아포스트로피)이면 `Y` |
| `residual` | 원획 계산에 실제로 쓴 나머지 획수 |
| `unicode_total_strokes` | `kTotalStrokes` 첫 값 |
| `wonhoek` | 성명학 원획 |
| `wonhoek_rule` | 원획을 정한 규칙, 그리고 `\|`로 이은 플래그(4절) |
| `hoek_ohaeng` | 원획 끝자리 오행: 1·2 木 / 3·4 火 / 5·6 土 / 7·8 金 / 9·0 水 |
| `radical_ohaeng` | 부수 자원오행 **휴리스틱**(5절). 출처가 갈리면 `金/土`처럼 둘 다 적음. 관행이 없으면 빈칸 |

| `radical_char` | 부수 정자(예: 85 → 水) |

| `khangul_raw` | `kHangul` 원문(표지 포함) |

| `wonhoek_check` | 원획 옥편 대조 권장이면 `Y`, 아니면 `N`(4절 '확인 권장 기준'). `scripts/name_search.py`의 '획확인' 플래그가 이 열을 그대로 쓴다 |

## 4. 원획 규칙

기호: K = 강희 부수 **정자** 획수 + 나머지 획수, T = 유니코드 총획.

한국 성명학의 원획법은 강희자전 획수를 기준으로 하고, 약자로 쓰는 부수를 정자 획수로 되돌린다. 아래 13개 부수가 그 대상이며, 각 값은 강희 부수 자체의 획수와 같다.

> 水(氵)=4, 手(扌)=4, 心(忄)=4, 犬(犭)=4, 玉(王)=5, 示(礻)=5, 衣(衤)=6, 艸(艹)=6, 肉(月 육달월)=6, 辵(辶)=7, 邑(阝 오른쪽)=7, 阜(阝 왼쪽)=8, 网(罒)=6

| 규칙 | 행 수 | 내용 |
|---|---:|---|
| `unicode-total` | 5,585 | K = T. 그대로 씀. 이미 정자 부수로 쓰인 글자 포함(泉, 志, 忠) |
| `radical-full` | 2,038 | 위 13개 부수에서 K > T. 정자로 환산(河 8→9, 道 13→16, 英 9→11, 育 8→10) |
| `kangxi-sum` | 397 | 다른 부수에서 K > T. 부속 성분을 현대 자형이 덜 센 경우(權 21→22, 娜 9→10, 健 10→11). 부수 老(125)가 耂(4획)로 쓰이면 4획으로 셈 |
| `total-gt-rs-check` | 56 | T > K. 기본은 T를 쓴다(成 7, 興 16, 者 9). 단 강희자전과 대자원 배열 위치가 **둘 다** 그 글자를 K 구간의 실제 수록자로 두는 25자는 강희 원획 원칙에 따라 K를 쓴다(`kx-dj-confirm`. 아래). 56자 모두 확인 권장 |
| `radical-variant-check` | 3 | 13개 부수가 더 긴 변형으로 쓰여 T > K. T를 씀(求·泰의 氺, 滕) |
| `radical-itself-check` | 1 | 才(手部 0획). 글자 자체가 독립 자형이라 T=3을 씀. 王은 Unicode가 `96.-1`로 적어 4획이 그대로 나옴 |
| `numeral-meaning` | 10 | 一~十은 의미수 1~10 |
| `override` | 4 | 대만 자형 때문에 T가 큰 예외: 延 7, 筵 13, 御 11, 禦 16(사유는 스크립트 `OVERRIDES`에 있음) |

### 자전 배열 위치 보정 (`kKangXi`, `kDaeJaweon`)

강희자전과 대자원은 모두 부수, 그다음 나머지 획수 순으로 글자를 배열한다. Unihan 위치값의 끝자리는 실제 수록자면 0, 사전에 없어 사이에 끼워 넣은 가상 위치면 0이 아니다. 실제 수록자 가운데 RS 값이 하나뿐인 글자를 참조열로 삼고, 각 글자의 앞뒤 이웃 4자의 최빈 부수와 나머지 획수로 그 글자가 놓인 구간을 추정한다. 이 추정은 통계적 방법이라 잡음이 있다.

- **RS 후보가 여럿인 글자**: 강희 구간에 맞는 후보를 고른다(`rs-by-kangxi-pos`, 18자). 예: 萬은 禸 대신 艸 → 15, 蒸은 火 대신 艸 → 16, 巡은 辵 대신 巛 → 7, 尹은 尸 → 4, 睡는 109.8 → 13, 琉는 96.7 → 12, 猪는 94.9 → 13, 卿은 26.10 → 12.
- **강희 확정 구간의 나머지 획수가 유니코드 값보다 클 때**: 강희 값으로 올린다(`kangxi-pos-residual`, 32자). 예(유니코드 총획→원획): 城 9→10, 誠 13→14, 著 13→15, 署 14→15, 響 20→22, 異 11→12, 翼 17→18. 盛·暑는 보정 결과가 T와 일치한다.
  - 대자원 위치로 교차 확인한 결과(32자): 같은 나머지 획수 19자, 대자원 구간 범위 안 7자(異·翼·署·響 등), 대자원 구간을 정할 수 없음 6자, **어긋남 0자**.
- **강희 구간이 쓰인 나머지 획수를 벗어나는데 위 보정에 해당하지 않을 때**: 값은 그대로 두고 `kangxi-pos:<부수>.<lo>[-<hi>]` 플래그만 단다(41자). 34자는 강희 구간이 더 작은 쪽이고(예: 姬, 熙, 剩, 犀), 7자는 더 큰 쪽이지만 구간이 한 값으로 확정되지 않아 올리지 않은 글자다(예: 奔, 整). 자료 사이에 값이 갈리는 글자라 **확인 권장**으로 센다. 예를 들어 姬는 유니코드 총획으로 10이지만 강희·대자원 배열 위치로는 9 구간이다. 41자 가운데 17자는 대자원 구간도 쓰인 값을 벗어나 `dj-pos`가 함께 붙는다(그중 14자는 강희와 같은 작은 쪽).
- **T > K인 `total-gt-rs-check` 글자**: 강희 확정 구간과 대자원 확정 구간이 모두 kRSUnicode의 나머지 획수와 같고, 두 자전 모두 실제 수록 위치일 때만 K를 쓴다(`kx-dj-confirm`, 25자): 僊13 卸8 呰8 嘴15 墀14 婣11 晸12 柴9 橚16 煕13 疵10 眥10 眦10 砦10 紫11 緻15 繡18 蜵14 訾12 貲12 雌13 露20 驌22 髭15 鷫23. 이 값은 유니코드 총획(T)보다 1 작다. 국내 작명서·작명 프로그램이 어느 값을 쓰는지는 이번에 확인하지 못했으므로 확인 권장을 유지한다. 나머지 31자(成·興·者 등)는 두 자전 중 하나라도 구간이 갈리거나 위치가 없어 T를 쓴다.
- **대자원 구간과 다를 때**: 쓰인 나머지 획수가 대자원 확정 구간 밖이면 `dj-pos:<부수>.<lo>[-<hi>]`를 남긴다(44자). **정보용**이며 이것만으로 확인 권장을 붙이지 않는다. 普·景·戰·越처럼 흔한 글자도 위치 추정 잡음으로 잡히기 때문이다.

### 육달월(月=肉) 위치

부수 肉(130)을 정자 6획으로 환산한(`radical-full`) 132자 가운데, 月이 왼쪽 변(⿰月□)이 아닌 27자에 `meat-moon-not-left`를 붙이고 **확인 권장**으로 센다. 값은 바꾸지 않는다. 月이 아래나 오른쪽에 있으면 육달월 환산을 하는지에 대한 관행을 이번에 출처로 확인하지 못했기 때문이다. 판정은 `moji.db`의 `ids` 표에서 한국(K) 출처 자형의 IDS를 우선해 첫 구성이 `⿰`·`⿲`이고 첫 성분이 月·⺼·⺝·肉인지로 본다.

> 해당 27자: 肓 肖 肩 肯 育 肴 胃 胄 背 胡 胤 胥 胷 能 脅 脊 脣 脩 腎 膂 膋 膏 膚 膺 臀 臂 臝 (교육용 10자: 肖 肩 肯 育 胃 背 胡 能 脅 脣)

### 확인 권장 기준 (`wonhoek_check` = Y)

- 규칙이 `total-gt-rs-check`·`radical-variant-check`·`radical-itself-check`·`override`이거나,
- 플래그 `multi-rs`·`rs-by-kangxi-pos`·`kangxi-pos-residual`·`kangxi-pos`·`meat-moon-not-left` 가운데 하나라도 붙은 행(스크립트의 `CHECK_RULES`·`CHECK_FLAGS`).
- 해당 행: **190자**. 규칙이 기본 셋(`unicode-total`·`radical-full`·`numeral-meaning`)이 아니거나 플래그가 하나라도 붙은 행은 712자이고, 나머지 522자는 정보용 규칙·플래그(`kangxi-sum` 규칙, `component-kangxi-diff`·`dj-pos` 플래그)만 해당하는 행이다.

## 6. 한계와 주의

1. **대법원 목록과의 시차**
   - Unihan의 인명용 표지는 2018년 목록(`kKoreanName` 최대 2018)까지만 반영되어 있다.
   - 대법원 인명용 한자는 2024-06-11 시행 개정으로 8,319자에서 **9,389자로 1,070자 늘었다**(한국경제 2024-05-23, 법률신문 보도). 이 추가분은 이 표에 **없다**.
   - 대법원 집계는 같은 글자를 발음별로 따로 세는 등 기준이 달라, 이 표의 8,094와 직접 비교할 수 없다.
   - 최종 판단은 항상 [대법원 인명용 한자 조회](https://efamily.scourt.go.kr/cs/CsBltnWrtList.do?bltnbordId=0000010)로 한다. 출생신고 직전에 자형과 지정 발음을 다시 확인한다.
2. **읽기**
   - `inmyeong_readings`에는 Unihan이 `N`/`E` 표지를 붙인 읽기만 들어 있다.
   - 인명용 한자표 비고에는 첫소리 ㄴ·ㄹ 한자를 소리 나는 대로 ㅇ·ㄴ으로 쓸 수 있다는 취지의 규정이 있다. 이를 위해 `dueum_readings`를 따로 계산해 두었으나, 실제 허용 여부는 대법원 조회로 확인한다.
3. **원획**
   - 원획은 자료마다 갈리는 글자가 있다. 이 표에서는 유니코드 총획과 강희자전(일부는 대자원도) 배열 위치가 가리키는 값이 다른 글자가 그렇다(예: 姬 10/9, 熙 14/13).
   - `wonhoek_check` = Y인 글자는 이름 후보로 쓰기 전에 옥편으로 다시 확인한다.
   - `override`는 4자뿐이다. 규칙으로 해결되지 않는 예외가 더 있을 수 있다.
4. **훈음**: libhangul 사전의 훈음은 대법원이 지정한 훈이 아니다. 한 글자 항목이 없거나 뜻이 비어 있는 글자가 905자 있다(예: 昀, 姊, 晚). 첫 뜻이 대표 훈과 다른 글자도 있다(예: 垠 '언덕 은' — 대법원 조회 훈은 '땅가장자리 은', 潤 '불을' — 통용 훈은 '윤택할 윤').
5. **자원오행**은 5절의 휴리스틱이다. 작명 프로그램마다 값이 다를 수 있다.
6. **이 표가 판단하지 않는 것**: 이 표는 사용할 수 있는 글자의 범위와 획수만 다룬다. 성명학적 길흉, 뜻의 적합성, 불용문자 여부는 판단하지 않는다.
